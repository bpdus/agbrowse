## 이어가기 위해 필요한 맥락

- 사용자는 Aside와 같은 자율 구조를 결정했습니다. Muse는 작업을 요청하고, Mac 옆 에이전트 루프가 다음 행동을 판단합니다. 최초의 VM 단계별 판단안은 채택하지 않습니다.
- 두 Mac을 함께 지원합니다. Codex·Claude CLI의 기존 로그인과 opencodex를 연결합니다. Pi 제공자 설정을 복제하지 않고 공통 설정을 읽는 방향입니다. 계정 토큰은 문서나 Git에 넣지 않습니다.
- 화면은 좌측 실제 탭과 대화 목록을 갖춘 Mac 앱입니다. pi-gui는 참고 후보입니다. React 소스를 가져와 제품에 통합한 상태는 아닙니다.
- 지정 어댑터는 https://github.com/iola1999/codex-control-chrome-mcp 와 https://pi.dev/packages/codex-computer-use-mcp 입니다. Chrome Web Store와 Bitwarden을 지원해야 합니다. 자체 Chromium에 어댑터가 연결되는지는 아직 검증하지 않았습니다.
- 초기 일반 Chrome 제어안에서 자체 Chromium 앱으로 목표를 구체화했습니다. 일상 웹페이지 탐색을 에이전트의 도구 허용 목록으로 제한하면 안 됩니다. 에이전트 브리지의 권한 경계는 유지합니다.

Chromium은 155.0.8059.40, 커밋 cfaadc5a132d78e1828635aa8405a499f3e14864로 고정했습니다. arm64 기반 빌드는 2026-10-14 13:05 KST에 끝났습니다. 첫 빌드는 4시간 12분 46초가 걸렸습니다. Xcode 27.0, SDK 27.0과 Metal Toolchain을 확인했습니다. 개발용 component 빌드이며, 서명·공증·제품 배포는 미검증입니다.

x64 전체 앱은 아직 빌드하지 않았습니다. iMac에서는 x64 C++ IPC 클라이언트의 소켓 검사만 확인했습니다. 이전 점검에서 iMac의 Node는 22였습니다. 다음 작업에서 Node와 Xcode 상태를 다시 확인해야 합니다. 고정 Chromium의 Xcode 27 도구는 ARM 전용이므로 Intel 호스트 계획은 별도로 검토합니다.

Pi 0.87.1의 실행기와 로컬 시험 제공자 왕복은 확인했습니다. 실제 계정 제공자, 서비스 엔진 등록, 버전별 런타임 캐시, 앱의 제공자 선택과 MCP 도구 연결은 남았습니다. 현재 mode=chat은 실제 CLI와 연결합니다. mode=browser는 waiting_user를 반환합니다. 실제 웹 작업이 완료됐다고 표시하면 안 됩니다.

최신 기본 경로 검사에서는 일반 검사 102개와 IPC 검사 20개가 통과했습니다. 기존 검사 하나는 긴 ROOT 경로를 가정하므로 제외했습니다. app/test/ipc.test.mjs의 “startIpcServer rejects unsafe baseDirs without touching the filesystem” 검사입니다. 짧은 기본 경로에서는 서버가 실제로 열려 assertion이 실패하고 정리가 누락될 수 있습니다. CHORE-02에서 명시적으로 긴 경로를 만드는 독립 fixture와 종료 처리를 수정해야 합니다. 전체 123개가 현재 경로에서 통과했다고 말하지 않습니다.

WebUI overlay는 별도 검사 트리에서 GN·TypeScript·리소스 생성과 새 C++ 파일 9개의 구문 검사를 통과했습니다. 부모 C++ 파일 3개는 생성 헤더 문제로 확인하지 못했습니다. 앱에 overlay를 실제 적용한 검증은 없습니다. native-webui 명세는 기반 앱과 Bitwarden 검사 뒤 적용하도록 정합니다.

이전 Documents/Codex 작업 폴더와 연결 경로는 삭제했습니다. 이전 위치나 work/agbrowse-plan-source 연결을 다시 만들지 않습니다. 과거 로그 안의 이전 경로 문자열은 역사적 기록입니다. 신규 명령은 기본 프로젝트 경로만 사용합니다.

work/의 소스, 빌드 결과, 브라우저 프로필과 비밀 설정은 Git에 올리지 않습니다. Git 작업환경 정리는 Chromium 작업 폴더 정리와 다릅니다. 기존 앱과 사용자 탭을 작업 종료를 이유로 닫지 않습니다. 폴더 이전 후 Synology Drive와 Spotlight의 높은 CPU 사용을 관찰했지만, 동기화 완료율은 확인하지 못했습니다. 현재 CPU 원인은 새로 측정해야 합니다.

이번 요청은 현재 작업의 커밋·PR·병합·Git 작업환경 정리를 허용합니다. 배포, 프로필 삭제, 다른 앱 설정 변경은 포함하지 않습니다. 이전 테스트 요청과 브라우저 개발 요구는 유지합니다. CLI Relay로 구현·교차 검토하고 계획과 스펙부터 작성합니다.
