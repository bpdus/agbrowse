# 목표 기능 메모: Aside가 하는 것 (정재 메모, 2026-10-12 01:09 KST)

에이전트 브라우저(bpdus/agbrowse 게이트웨이)의 웹 인식·조작 방식에 아래 기능을 목표로 포함한다. 아직 계획·구현 전이며, 우선순위와 범위는 정재 승인 후 정한다.

- 브라우저 자체라서 내가 로그인한 사이트를 그대로 사용
- API, 커넥터 없이 어떤 웹사이트든 직접 조작
- 내 기기에서 로컬로 실행, 작업과 메모리는 내 기기에 보관
- 기존 브라우저의 기록, 쿠키, 북마크 가져와 바로 시작
- Vault로 비밀번호를 AI에 노출하지 않고 자동 로그인
- 결제 카드도 결제 폼에 자동입력
- 에이전트의 자격증명 사용 기록 확인
- 결제, 게시, 메시지 같은 민감한 작업은 내 확인 후 실행
- ChatGPT, Claude, GitHub Copilot 구독 그대로 연결
- 브라우징 기록을 메모리로 바꿔 매번 맥락 설명 생략
- 어떤 일에 어떤 사이트를 쓰는지 기억
- 막혔던 사이트에서 성공한 경로 기억
- 작업이 끝나면 사람, 회사, 결정사항 자동 정리
- 메모리를 내 기기에 마크다운 파일로 저장하고 직접 수정
