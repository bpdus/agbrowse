# 정재 결정 (2026-10-11)
1. 포크: GitHub `bpdus/agbrowse` (lidge-jun/agbrowse 포크). 이 포크가 구현 기준이며 PR은 이 포크로.
2. 첫 지원 사이트: 네이버(조회 → 장바구니 → 승인 결제).
3. 실행 계정: 결제 단계까지 iMac의 기존 jjbyun 계정 하나로 운영(전용 계정 분리 안 함). 대신 에이전트 전용 Chrome 프로필은 분리.
4. 승인: 버튼 또는 명시적 답장. 필수 조건: 승인 결과를 요청한 에이전트가 직접 확인할 수 있어야 한다(에이전트가 못 봐서 승인이 전달되지 않는 구조 금지). 예: 게이트웨이가 승인 요청을 만들고 Grok Bot 채팅에 버튼/답장으로 묻고, 승인 결과는 게이트웨이의 승인 상태 조회(MCP 도구)로 에이전트가 읽고, 실행은 그 승인 토큰으로만 가능.
